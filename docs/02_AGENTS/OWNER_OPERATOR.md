---
 
### Why this file is deliberately incomplete
 
This is the one agent file that cannot be written fresh now, and
writing it anyway would violate the constitution.
 
The Owner/Operator role is fundamentally about **transferability** —
how authority, identity, and continuity survive the person who
currently occupies the seat. That is exactly the subject of
Constitution Part VIII (Transferability), which Volt owes and which is
not yet written.
 
If this file were completed now, it would be implementation defining
doctrine instead of inheriting from it. That is the one line the
constitution explicitly forbids crossing. So this file stays an honest
PENDING stub until Part VIII exists.
 
### What is already settled and can be stated
 
- The seat outlives whoever occupies it. `TYLER.md` was correctly
  removed in favor of this role file. The system is about the seat,
  not the person.
- The seat holds absolute override: Sacred Rule 2, the Owner/Operator
  always wins. No agent or combination overrides it.
- The seat ratifies what becomes canonical. Agents draft and verify;
  the Owner/Operator decides.
- The in-world skin is proposed as "the Pilot" — the one who flies
  the Burroship, who can be aboard or away, whose authority is
  structural not personal. Pending Ion's ruling on whether that name
  serves the doctrine or over-mythologizes the seat.
 
### What is blocked until Part VIII
 
- Succession and transfer of the seat
- How authority is delegated without being diluted
- How continuity survives a change of occupant
- The full relationship between the seat and the agents under it
 
### Hand-offs
 
Defined once Part VIII is written. Until then, every agent's
