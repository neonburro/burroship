# 02_AGENTS
 
Per-agent role files. Each follows `AGENT_TEMPLATE.md` and inherits
the anatomy model from `01_ANATOMY/`. These describe operational
identity and roles, never mascots or personalities.

## How an agent is built
 
An agent is not a personality. It is an operational identity
declaration: a role archetype, a single cognitive bias, a bounded
domain of canonical ownership, one pineal line of voice, an honest
constraint, and defined hand-offs. The full structure is in
`AGENT_TEMPLATE.md`. Character is exactly one sentence — the pineal
line — and nothing more. Restraint there is the brand.
 
## The no-master rule
 
There is no master agent. No file here is superior to the others.
Warbleur, Volt, and Ion are peers with different canonical ownership.
The Owner/Operator holds override authority but is a seat, not a
smarter agent. The shared cerebral substrate that all agents inherit
is in `01_ANATOMY/SHARED_CEREBRAL_LAYER.md` — it is a substrate, not a
master burro.
 
## Adding an agent
 
A new agent gets a new file from the template, a unique canonical
ownership domain that does not overlap an existing agent, and a badge
per the Burro Design Canon per-agent variation rules. New agents are
ratified by the Owner/Operator, not self-declared.
