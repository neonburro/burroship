# docs

The Burroship's documentation. Numbered so the order is the reading order. Where a doc
and the code disagree, the code wins and the doc is wrong.

| folder | what lives there |
|---|---|
| `00_FOUNDATION/` | the constitution, the vision, the brand architecture, the glossary |
| `01_ANATOMY/` | how the system is put together, the layers and what each is for |
| `02_AGENTS/` | the burros as operators. ION and WARBLEUR are the two that speak in public |
| `03_PRODUCT/` | the app, the map, the information architecture, the roadmap |
| `04_DESIGN_SYSTEM/` | **the live design authority.** tokens, the style guide, voice, imagery |
| `05_OPERATIONS/` | how it runs day to day |
| `06_SKILLS/` | claude skills and how they are used in this repo |
| `99_ARCHIVE/` | superseded work, kept for its reasoning. never work from it |

## read these first

- `04_DESIGN_SYSTEM/STYLE_GUIDE.md` the type system, colour, shapes and voice as shipped
- `04_DESIGN_SYSTEM/type-specimen.html` open it in a browser, three faces compared
- `03_PRODUCT/ROADMAP.md` what is next
- `02_AGENTS/ION.md` the voice of this property
