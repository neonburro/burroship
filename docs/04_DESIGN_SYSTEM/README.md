# 04_DESIGN_SYSTEM
 
How the brand looks, sounds, and moves. Inherits from the Burro
Design Canon and the live `src/styles/index.css` tokens. Tokens are
semantic in code; poetic fruit names live only in the brand naming
layer, never the raw implementation layer.

## The through-line
 
The design system is implementation. It inherits from the canon and
the live tokens and never redefines them. The single open value in
the entire system — the accent hue — is isolated to `TOKENS.md` so
everything else is complete and nothing needs rewriting when Volt
finalizes the fruit palette.
 
## The discipline
 
Every file here resists its own inflation. Voice docs that become
manifestos, motion docs that perform, imagery docs that drift into
brand-poetry — these are the failure modes this domain is most prone
to. The shortest honest statement is the most on-brand one.
