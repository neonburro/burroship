## The now / next / later model
 
Every page declares each claim's reality state. This is the content
layer of the same honesty discipline that runs the whole system:
never present staged or aspirational as shipped.
 
- **Now** — exists and is real today. Stated plainly.
- **Next** — being built or staged. Stated as in progress.
- **Later** — the system is clearly evolving toward it. Stated as
  direction, never as promise.
 
A page that lists Later items as Now has inverted the discipline and
reads as overpromise. The model exists so the site can talk about
agents, memory, mapping, automation, and world-state without lying
about what is live.

**Job:** orient a capable visitor in fifteen seconds, then let them
go deep where they choose.
 
1. **Hero** — world entry, one-sentence thesis, one primary action,
   one secondary. **STATUS: PENDING-ASSET.** The hero requires the
   produced Burroship render (canon v1.1 Section 2.5, Petrified Plum
   signal leakage, desktop-wide / mobile-portrait). Until that asset
   exists this section is a structural placeholder. It is the one
   hard gate on the homepage and it is honestly marked, not faked.
2. **The World** — short, the Compound as a real mountain field
   station. Links to `/compound/`. Now/next/later applies.
3. **The Intelligence Layer** — short, Neon Burro: agents, council,
   systems. Links to `/neon-burro/`. Distinct from Burroship.
4. **Operational Surfaces** — short, Pulse: client ops, admin,
   automation. Links to `/pulse/`.
5. **What's Coming Online** — future-facing, explicitly Later-tagged.
   Deployments, memory, mapping, world-state. No destination yet,
   and that is honest, not a gap.
6. **Closing** — an invitation to explore the world. Not a sales
   footer, not a generic CTA.

IA does not pretend otherwise. Five of six home sections and all four
destination pages can be structured and written immediately; the hero
waits on a produced render that only the Owner/Operator can make. The
critical path for the homepage is the hero brief and the render, not
this IA.
