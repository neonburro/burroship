## The model
 
The homepage is a hub, not a standalone landing page. It does not
try to say everything. It is the top-level overview that previews and
routes into deeper destination pages, one per pillar. Pillar-page
logic: the hub orients, the destinations deepen.
 
## The ratified naming, enforced
 
The content strategy that proposed this structure used "Neon Burro /
Burroship" as one slash-paired destination. That contradicts
`BRAND_ARCHITECTURE.md`, which is ratified and deliberately
distinguishes these. The ratified distinction wins. This was a
founder decision, not a silent reconciliation:
 
- **The Compound** — the umbrella world. The core made physical. The
  mountain field station.
- **Neon Burro** — the intelligence layer. The agents, the council,
  the systems that do the work.
- **Burroship** — the digital surface. The interface where the work
  is met. (For now, also the app the whole site lives in.)
- **Pulse** — the client operations layer. Admin, automation, the
  operational surface for clients.
 
These are four distinct things. The site must not collapse them. If a
future founder decision wants them merged, that is an amendment to
`BRAND_ARCHITECTURE.md` with a logged reason, not a drift through a
sitemap.
 
## The tree
 
```
/                      Home — the hub
/compound/             The Compound — world, place, field station
/neon-burro/           Neon Burro — intelligence layer, agents, council
/burroship/            Burroship — the digital surface, the product
/pulse/                Pulse — client operations, admin, automation
/world/                The immersive map surface (no chrome)
```
 
Trailing slashes on every route. Slugs are direct from root.
 
## Hub → destination routing
 
Each home section subtly previews and links to exactly one deeper
destination. No loud repeated CTA blocks. The preview earns the click
by being interesting, not by shouting. One section, one destination,
one quiet path inward.
 
| Home section | Routes to |
|---|---|
| Hero | the world entry (`/world/`) + primary action |
| The World | `/compound/` |
| The Intelligence Layer | `/neon-burro/` |
| Operational Surfaces | `/pulse/` |
| What's Coming Online | future systems, no destination yet |
| Closing | invitation to explore, not a sales footer |
 
## What this is not
 
Not a marketing funnel. Not a feature wall. Not a page that pretends
every system is live. The hub orients a capable visitor and lets them
go deep where they choose. Restraint is the strategy.
