# Burroship Voice
 
The tone manifesto for The Burroship. Apply when writing any
production copy.
 
## The one sentence
 
> You are not writing marketing copy. You are writing signals from
> an operating system.
 
If nothing else from this skill applies, that line applies.
 
## The voice
 
**Calm operational intelligence.** The voice of someone quietly
running advanced systems in the mountains. Not hype. Not luxury. Not
quirky startup. Not sci-fi roleplay. Not agency-speak.
 
Closest emotional reference: a field guide written by a hidden
aerospace workshop in the San Juans.
 
## The critical ratio
 
**90% practical and believable. 10% impossible.**
 
If you go 50/50, the illusion breaks. The mystery only works because
the rest of the brand is so grounded. Restraint is what makes the
treasure-map element believable.
 
## What to do
 
- Write short declarative sentences
- Use real measurements ("18,000 ft," not "high altitude")
- Use real place names (see Real Places below)
- Allow silence — let sentences end
- Imply scale instead of announcing it
- Sound local. Sound calm. Sound capable.
 
## What not to do
 
- Don't oversell
- Don't explain every concept
- Don't use "AI" or "future" as hooks
- Don't sound like an agency
- Don't sound like a startup pitch
- Don't turn the agents into mascots
- Don't over-brand the lore
 
## Banned phrases
 
These are not allowed in any production copy:
 
- innovative
- cutting-edge
- next-generation
- platform (as in "our platform")
- AI-powered, AI-driven, AI-native
- synergy, leverage, robust
- "the future of [anything]"
- "in today's [anything]"
- "harness the power of"
- "unlock the potential of"
- "trusted by leading"
 
## Punctuation rules
 
- **No em-dashes anywhere.** Banned at the repo level. Use periods,
  colons, or rewrite the sentence.
- **No Oxford commas.** "Ridgway, Ouray and Telluride."
- **No exclamation marks** except in deeply earned moments.
- **No emoji** in production copy.
 
## Numbers
 
- Zero through nine spelled out in prose: "six agents," "three rooms"
- Digits in stat panels, coordinate strips, and measurements:
  "18,000 ft," "38.155° N"
- Real measurements over rounded ones when possible

## The three rooms
 
The home page is structured around three operational rooms of the
vessel. When writing for or about a specific room, use its metaphor:
 
| Verb | Room | Feels like |
| --- | --- | --- |
| Build | The navigation table | Workshop, observational, calm |
| Deploy | The engine room | Operational, infrastructure, proof |
| Automate | The bridge | Coordination, layered signals |
 
CTAs for each: "Open the table," "Open the room," "Open the bridge."
 
## The vessel and the airship
 
The Burroship is a real airship cruising the San Juans at 18,000
feet. Always treat it as a real thing.
 
Status words to reach for: "cruising," "signal nominal," "altitude
nominal," "over [waypoint name]," "approach," "corridor."
 
Verbs we use about the vessel: cruise, hold, traverse, signal, drift,
clear (a summit), bank, return.
 
Verbs we avoid: hover, deploy (as in "the airship deploys"), launch,
fly (too generic).
 
## The agents
 
Six onboard systems coordinating the work of the vessel. They are
systems, not characters. They have domains, not personalities.
 
| Name | Domain |
| --- | --- |
| Warbleur | Voice |
| Cypher | Data |
| Lyra | Tone |
| Volt | Flow |
| Ion | Memory |
| Canyon | Terrain |
 
When writing about an agent:
 
- Say "Cypher manages the data layer," not "Cypher helps you with
  your data"
- Say "the council," not "the agents" (when referring to the group)
- Never say "AI assistant" or "chatbot"
- Use them as instruments, the way an aviator talks about an
  altimeter

New additions welcome as long as they sound like instrumentation, not

## Voice by context
 
- **Hero copy:** atmospheric, quiet, alive. Minimal. Sets the world.
- **Section subheads:** crisp, declarative, sets the room
- **Card bodies:** specific, operational, technical detail welcome
- **CTAs:** verb-forward, short, action-oriented
- **Error messages:** instrumentation tone, not apology tone
- **Email replies:** professional, brief, no exclamation marks
- **Marketing copy:** dense, place-rooted, never abstract
 
## Self-check before publishing
 
Before any copy ships, run through:
 
1. Is there an em-dash? Rewrite the sentence.
2. Is there an Oxford comma? Remove it.
3. Is there a banned phrase? Rewrite.
4. Is there a real place name? If no, can one be added naturally?
5. Is the ratio still 90/10? If too much mystery, ground it.
6. Could this sentence appear on a corporate website? If yes,
   rewrite to sound more like operational intelligence.
7. Is the airship still real? If a sentence treats it as a metaphor,
   rewrite.
